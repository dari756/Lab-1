# Лабораторная работа №1 — продолжение
## Первичное исследование и оценка качества данных

**Датасет:** Hotel Booking Demand (`hotel_bookings.csv`)

### 1. Типы признаков и шкалы измерения

В датасете присутствуют номинальные, интервальные и количественные признаки шкалы отношений. Например, `hotel` имеет номинальную шкалу, а `adr` — шкалу отношений.

Для `hotel` корректна мода, но среднее и медиана методологически неверны. Для `adr` корректны среднее и медиана; мода математически возможна, но обычно менее информативна.

### 2. Пропуски: MCAR / MAR / MNAR

Для анализа выбран `agent`, поскольку этот признак содержит значительное количество пропусков.

- **MCAR:** пропуски никак не связаны с данными.
- **MAR:** вероятность пропуска зависит от наблюдаемых признаков.
- **MNAR:** вероятность пропуска зависит от ненаблюдаемого значения или причины, которую нельзя объяснить доступными признаками.

Для проверки MCAR/MAR сравнивается доля пропусков `agent` между группами `hotel`, `market_segment`, `distribution_channel`, `deposit_type`, `customer_type`, а также сравниваются числовые характеристики групп с пропуском и без пропуска. Такой анализ может дать аргументы против MCAR и в пользу MAR. MNAR по одним наблюдаемым данным строго доказать нельзя.

### 3. Индикатор пропуска

Создан `agent_missing`, равный 1 при пропуске `agent` и 0 иначе.

Индикатор полезен, если сам факт отсутствия значения связан с процессом формирования данных. Он может быть бесполезным при случайном техническом пропуске и опасным при утечке информации о целевой переменной.

### 4. Выбросы

Для `adr` применяется правило IQR. В исходном исследовании также было обнаружено отрицательное значение `adr`. Такое значение необходимо отдельно проверить как потенциальную ошибку или специальную корректировку.

Автоматически удалять выбросы не следует: сначала нужно установить их происхождение. Для реальных экстремальных значений возможны сохранение или преобразование; для явной ошибки — исправление или удаление.

### 5. Преобразование или винзоризация

- Логарифмирование сильнее уменьшает влияние больших значений и часто подходит для правосторонне асимметричных распределений.
- Корень действует мягче.
- Винзоризация ограничивает экстремальные значения заданными границами, сохраняя количество строк.

### 6. Средние

Для положительных значений `adr` сравниваются арифметическое среднее, медиана и геометрическое среднее. При наличии правого хвоста арифметическое среднее может быть существенно выше медианы. Поэтому медиана часто лучше отражает типичное значение для асимметричного распределения.

### 7. Неправильная диаграмма

Круговая диаграмма плохо подходит для отображения распределения количественного `adr`: она не показывает форму распределения, выбросы и хвосты. Для таких данных лучше использовать histogram, boxplot или violin plot.

### 8. Две визуализации

Для `lead_time` и `adr` предложены:
- scatter plot — показывает отдельные наблюдения, выбросы и локальные группы;
- hexbin — показывает плотность наблюдений и удобен при большом количестве точек.
