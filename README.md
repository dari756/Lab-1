# Лабораторная работа №1: Первичное исследование и оценка качества данных

## Описание проекта

Первичный анализ датасета **"Hotel Booking Demand"** в рамках дисциплины **"Интеллектуальный анализ данных"**.

**Предметная область:** данные о бронированиях двух типов отелей — City Hotel и Resort Hotel. Датасет содержит информацию о бронированиях, клиентах, датах заезда, длительности проживания, стоимости номеров, отменах и каналах бронирования.

**Цель лабораторной:** провести первичное исследование датасета, построить паспорт данных, оценить качество данных и выявить основные проблемы, которые необходимо учитывать при дальнейшем анализе.

## Структура проекта

- `notebooks/01_data_understanding.ipynb` — основной Jupyter Notebook с первичным анализом данных
- `report/quality_report.md` — текстовый отчёт с результатами исследования и выводами
- `data/hotel_bookings.csv` — исходный датасет

## Датасет

Файл `hotel_bookings.csv` содержит **119 390 записей о бронированиях** двух типов отелей:

- City Hotel;
- Resort Hotel.

В рамках лабораторной работы анализируются:

- структура датасета;
- типы признаков;
- пропущенные значения;
- дубликаты;
- подозрительные значения;
- выбросы;
- основные статистические характеристики;
- зависимости между признаками.

## Основные проблемы качества данных

### Пропущенные значения

Наиболее заметные пропуски присутствуют в признаках:

- `company`;
- `agent`;
- `country`;
- `children`.

Пропуски необходимо учитывать перед дальнейшим статистическим анализом и построением моделей.

### Дубликаты

В датасете обнаружены полные дубликаты строк. Перед построением моделей необходимо определить, являются ли они действительно повторными записями или представляют собой допустимые наблюдения.

### Выбросы

Для `adr` выполнено обнаружение выбросов с помощью межквартильного размаха (IQR).

Кроме того, обнаружено отрицательное значение `adr`, которое требует отдельной проверки как потенциально некорректное значение.

### Подозрительные значения

Были обнаружены записи с нулевым количеством гостей. Такие наблюдения необходимо дополнительно исследовать и определить, являются ли они ошибками или особенностями исходного источника.
