## Датасет

`hotel_bookings.csv` содержит данные о 119 390 бронированиях двух типов отелей: City Hotel и Resort Hotel.

В работе анализируются структура данных, пропуски, дубликаты, подозрительные значения, выбросы и основные зависимости между признаками.

## Запуск

1. Открыть `notebooks/01_data_understanding.ipynb` в Jupyter Notebook или Google Colab.
2. Убедиться, что файл `hotel_bookings.csv` находится в каталоге `data/`.
3. Выполнить ячейки ноутбука сверху вниз.

Ноутбук рассчитан на запуск из каталога `notebooks/`, поэтому путь к данным указан как `../data/hotel_bookings.csv`.

## Основные результаты

- 119 390 строк;
- 32 исходных признака;
- 31 994 полных дубликата;
- значительное количество пропусков в `company`;
- 16 340 пропусков в `agent`;
- 488 пропусков в `country`;
- 3 793 выброса `adr` по правилу IQR;
- обнаружено отрицательное значение `adr`;
- обнаружены записи с нулевым количеством гостей.

Подробные выводы находятся в `report/quality_report.md`.
