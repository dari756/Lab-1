# Лабораторная работа №1: Первичное исследование и оценка качества данных

## Описание проекта

Первичный анализ датасета **"Hotel Booking Demand"** в рамках дисциплины **"Интеллектуальный анализ данных"**.

**Предметная область:** данные о бронированиях двух типов отелей — City Hotel и Resort Hotel. Датасет содержит информацию о бронированиях, клиентах, датах заезда, длительности проживания, стоимости номеров, отменах и каналах бронирования.

**Цель лабораторной:** первичное исследование датасета, построение паспорта данных и оценка качества данных.

## Структура проекта

- `notebooks/01_data_understanding.ipynb` — основной Jupyter Notebook с анализом
- `notebooks/02_lab1_continuation.ipynb` — продолжение лабораторной работы
- `report/quality_report.md` — текстовый отчёт с выводами
- `report/quality_report_continuation.md` — отчёт по продолжению лабораторной работы
- `data/` — датасет
